## Featured Projects

### DermaCure AI — AI-Powered Skin Screening & Dermatologist Booking

> Full-stack MERN healthcare platform with TensorFlow.js-powered skin condition analysis, secure authentication, image upload handling, and real-time appointment booking.

**Stack:** React.js · Node.js · Express.js · MongoDB · TensorFlow.js · JWT · Multer · Tailwind CSS · Vercel · Render

**What it does**
- Allows users to upload skin images for AI-powered analysis across multiple skin condition categories
- Provides role-based access for patients, doctors, and admins
- Supports dermatologist appointment booking with dynamic slot conflict detection
- Deploys frontend and backend separately using modern cloud deployment workflows

**Engineering decisions**
- Used **TensorFlow.js** for client-side model inference to reduce backend compute dependency
- Used **JWT + bcrypt** for secure authentication and credential handling
- Used **Multer + Express.js** for image upload and preprocessing workflows
- Used **MongoDB Atlas** for flexible healthcare-related document storage
- Used **Tailwind CSS** to build responsive dashboards across mobile, tablet, and desktop views

**Challenges solved**
- Optimized AI analysis through image preprocessing and model warm-up
- Implemented role-separated authorization for patient, doctor, and admin flows
- Built booking conflict detection to reduce scheduling errors
- Maintained responsive UI consistency across multiple viewport sizes
