## Featured Projects

### 🧬 DermaCure AI — AI-Powered Skin Screening & Dermatologist Booking

> Full-stack MERN healthcare platform with TensorFlow.js skin condition analysis and real-time appointment booking.

**Stack:** React.js · Node.js · Express.js · MongoDB · TensorFlow.js · JWT · Multer · Tailwind CSS · Vercel · Render

- TensorFlow.js model inference pipeline with sub-2-second analysis across 5+ skin conditions
- JWT authentication with role-separated access: patient / doctor / admin
- Multer image upload pipeline with Express.js preprocessing and model warm-up
- Deployed with CI-ready pipelines — frontend on Vercel, backend on Render

[![Live Demo](https://img.shields.io/badge/Live_Demo-000000?style=flat-square&logo=vercel&logoColor=white)](https://derma-ai-psi.vercel.app)
[![GitHub](https://img.shields.io/badge/GitHub-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/bharathgopalswamy/DermaAI)

### 🏥 MedCare — Healthcare Appointment Management System

> Django-powered appointment platform with Google Calendar API integration and OAuth2 authentication.

**Stack:** Django · JavaScript · MySQL · Google Calendar API · OAuth2 · Session Auth

- Normalized MySQL schema across 3 entities (patients, doctors, appointments) with indexed lookups
- Google Calendar OAuth2 sync eliminates manual scheduling — reduced admin effort by ~30%
- Booking conflict detection engine prevents double-bookings across all appointment flows
- Django CBVs and permission decorators secure all patient-facing and admin endpoints

[![GitHub](https://img.shields.io/badge/GitHub-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/bharathgopalswamy/DoctorPatient)
